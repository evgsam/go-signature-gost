# ЭЦП ГОСТ Р 34.10-2012 (512 бит)

Реализация электронной цифровой подписи по ГОСТ Р 34.10-2012 (512 бит) на языке Go.

## Описание

Данная программа выполнена в рамках практического задания учебного курса
"Криптографические методы защиты информации" студентом Самарин Евгений.

Программа реализует алгоритм ЭЦП по ГОСТ Р 34.10-2012 с использованием эллиптической кривой над конечным полем. Набор параметров — id-GostR3410-2012-512A (OID 1.2.643.7.1.2.1.2.1, 512-битный ключ).

## Возможности

- Генерация ключевой пары (закрытый d, открытый H = d*G)
- Подписание файлов с формированием ЭЦП (r, s)
- Проверка ЭЦП файлов
- Сохранение и загрузка ключей в текстовом формате
- Сохранение и загрузка подписей в текстовом формате

### Меню программы

После запуска отображается меню с опциями:

1. **Сгенерировать ключевую пару** — создаёт пару ключей и сохраняет:
   - Закрытый ключ d → `private.key` (hex-строка)
   - Открытый ключ H → `public.key` (формат: X\nY, координаты в hex)

2. **Подписать файл** — подписывает файл и сохраняет подпись:
   - Вводится путь к файлу для подписи
   - Вводится путь к закрытому ключу (private.key)
   - Вводится путь для сохранения подписи (signature.sig)
   - Подпись сохраняется в формате: r\ns (каждая компонента в hex)

3. **Проверить подпись** — проверяет подпись файла:
   - Вводится путь к подписываемому файлу
   - Вводится путь к файлу подписи (signature.sig)
   - Вводится путь к открытому ключу (public.key)
   - Выводится результат проверки

4. **Выход** — завершение программы

### Форматы файлов

- **private.key** — hex-строка (закрытый ключ d)
- **public.key** — две строки: X\nY (координаты открытой точки H в hex)
- **signature.sig** — две строки: r\ns (компоненты подписи в hex)

## Алгоритм ЭЦП (ГОСТ Р 34.10-2012, 512 бит)

### Генерация ключей
1. Генерируем случайное число d ∈ [1, Q-1] — закрытый ключ
2. Вычисляем H = d*G — открытая ключевая точка

### Подписание
1. Вычисляем e = hash(msg) mod Q (хеш алгоритмом Стрибог-512)
2. Генерируем случайное k ∈ [1, Q-1]
3. Вычисляем точку C = k*G
4. r = C.X mod Q
5. s = (r*d + k*e) mod Q
6. Возвращаем (r, s)

### Проверка
1. Проверяем корректность r, s: 0 < r < Q, 0 < s < Q
2. e = hash(msg) mod Q
3. v = e^(-1) mod Q
4. z1 = s*v mod Q, z2 = -r*v mod Q
5. C' = z1*G + z2*H
6. r' = C'.X mod Q
7. r' == r ⇒ подпись верна

## Ограничения (учебный проект)

Данная программа является учебным проектом и имеет следующие ограничения:

- **Отсутствие защиты от side-channel атак.** Реализация не использует защит от каналов утечки информации (тайминг-атаки, power analysis и т.д.).
- **Случайность k.** В производстве используется криптографически стойкий генератор псевдослучайных чисел (crypto/rand), но для учебных целей важно понимать, что повторное использование k приводит к утечке закрытого ключа.
- **Нет схемы дополнения сообщения (padding).** В данной реализации не используется дополнительная обработка сообщения перед хешированием. Для практического применения необходимо использовать стандартные схемы (например, EMSA-PSS для RSA или аналогичные для ECC).
- **Не оптимизировано по скорости.** Код не проходил оптимизацию и не предназначен для использования в промышленных системах.
- **Только один набор параметров.** Реализован только один набор параметров кривой (id-GostR3410-2012-512A, OID 1.2.643.7.1.2.1.2.1, 512 бит). Поддержка других наборов параметров не реализована.
